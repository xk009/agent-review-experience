# Review Package 模板

这是人工判断的导航，不是放行证明。尖括号字段必须替换；未知就写“未确认”及影响。
仅选择适用扩展，不机械输出所有表格。

## 通用首屏

```markdown
# <任务名称> · 审阅交付

## 结果与状态
<已实现 / 部分实现 / 待验证 / 待验收；一句话结论>

## 相对上一轮
<首次交付可省略。新增、修改、解决、仍待处理；失效证据。>

## 关键变化
<按行为或结论组织；默认不超过三项，关键风险不可省略。>

## 优先审阅
| 位置 / 入口 | 要判断什么 | 为什么值得检查 |
| --- | --- | --- |
| <真实路径、符号或段落> | <具体问题> | <影响 / 风险> |

## 验证与缺口
| 检查 | 实际结果 | 对应版本 / 时间 | 证据入口 |
| --- | --- | --- | --- |
| <命令或方法> | <通过 / 失败 / 未执行 / 过期> | <快照与时间> | <真实路径；没有则写缺失> |

关键风险与未覆盖项：<保持可见，不折叠、不用“整体正常”掩盖。>
需要人工决策：<没有则省略。给选项、推荐与理由。>

## 范围与证据
任务类型：<code / document / analysis>
源版本或内容哈希：<标识>
生成时间：<含时区>
纳入范围：<范围>
排除范围：<范围与理由>
快照状态：<已核对 / 不完整 / stale>
原始证据入口：<差异、源文档、数据、日志>

## AI 预审
执行方式：<独立子代理 / 同会话自查 / 未执行>
检查范围、发现与限制：<如实填写；无发现不是无风险。>
```

## 代码扩展：快照与行为契约

```markdown
比较基线：<base SHA；直接比较或 merge-base>
HEAD：<SHA>
暂存区：<相关文件 blob 标识，含删除状态>
工作区 / 新增文件：<路径 → SHA-256，删除项标 deleted>
审阅前后是否一致：<一致 / 变化及影响 / 无法核对>
二进制 / 子模块 / 其他限制：<说明>

| 场景 / 输入 | 原行为 | 期望新行为 | 实现位置 | 验证 |
| --- | --- | --- | --- | --- |
| <默认值、异常、状态切换等> | <行为> | <行为> | <路径 / 符号> | <证据或缺口> |

同仓库惯例：<相关实现入口；沿用或偏离什么及其理由。>
```

快照至少区分提交、暂存、未暂存与相关新增文件。不要用一个 HEAD 代替工作区版本。
验证只对其实际覆盖的快照、环境与范围有效。

## 文档扩展：结论、变化与依据

```markdown
读者及需要作出的决定：<对象与问题>
新旧版本入口：<真实路径 / 版本>
核心结论：<事实与建议分开>
变化地图：<段落 → 改了什么 → 对判断的影响>
事实 / 推断 / 建议：<分别标识；外部事实有来源与核对日期>
待确认假设与反例：<内容>
```

文档验证可以是来源核实、内部一致性、数字复算、链接和渲染检查；不要虚构“单测通过”。

## 分析扩展：口径与复现

```markdown
数据来源与版本：<入口 / 哈希>
时间窗与样本数：<边界，含失败 / 取消 / 重试的处理方式>
指标定义：<例如排队、执行、人工等待是否计入耗时>
成本口径：<实际账单 / 按价目表估算 / 套餐用量，不能混用>
可复现方法：<查询 / 脚本 / 计算规则>
观察事实：<数据直接支持什么>
原因假设：<不能仅由相关性确定什么>
建议与验证方法：<下一步实验，不伪造改善幅度>
```

## 发现记录

```markdown
### <ID> · <严重程度> · <问题>
位置：<真实路径 / 符号 / 行号>
触发条件 → 错误行为 → 影响：<因果链>
依据与待确认假设：<证据>
最小修复或验证方法：<建议>
处置：<已确认 / 待确认 / 不采纳及理由>
```
